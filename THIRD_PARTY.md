# Third-Party Libraries & Tools

The CITRIX frontend leverages standard, high-performance web libraries complying with project restrictions:

| Library / Tool | Version | Purpose | License |
| :--- | :--- | :--- | :--- |
| **Three.js** | 0.160.0 | Core interactive 3D WebGL isometric campus scene, procedural building geometries, shadows & materials | MIT |
| **Three.js OrbitControls** | 0.160.0 | Damped camera orbit, pan, pitch, and zoom controls | MIT |
| **Tailwind CSS** | 3.4.x (CDN) | Enterprise command-center design system, responsive grids, dark navy color palette | MIT |
| **Google Fonts (Inter & JetBrains Mono)** | Latest | Clean typography, readable tables, and numeric information density | OFL |
| **Python http.server** | 3.13.0 | Lightweight standalone development & review server | PSF |
