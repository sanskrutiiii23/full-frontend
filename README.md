# full-frontend · CITRIX CampusOS

> Comprehensive frontend prototype for CITRIX (Chilika Institute of Technology CampusOS) unifying the 3D Cinematic Landing Page and full multi-role operational workspace.

## Features
- **Cinematic 3D Landing Page**: Spatial twin, institutional impact metrics, and CP-SAT decision pipeline.
- **Multi-Role Workspace**: Dedicated portals for Admin (Dean), Department Coordinator, Faculty, and Student Clubs.
- **Natural Language & Hinglish AI Booking**: LLM-assisted request extraction with strict deterministic validation.
- **Spectra Week Priority Arbitrage**: 6-tier institutional hierarchy with transparent reasoning.
- **Disruption Management & Rescheduling**: Minimal-perturbation solver with side-by-side visual diff comparison.
- **Midsem Exam Scheduling**: Automated timetable synthesis with halved effective room capacities.
- **5-Minute Video Walkthrough Script**: Included in [`DEMO_SCRIPT.md`](./DEMO_SCRIPT.md).

## Running Locally
```bash
python3 server.py 8000
```
- **Landing Page**: [http://localhost:8000/](http://localhost:8000/)
- **Workspace Demo Portals**: [http://localhost:8000/login](http://localhost:8000/login)
